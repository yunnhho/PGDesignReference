**규칙으로 남기지 않은 것 (더 안전하다고 판단)**
- `Refresh` 같은 `Control` 멤버와 같은 메서드 이름(B): 빌드 경고(CS0108)가 이미 잡고, 경고 0 기준이 있다.
- 관리자 비밀번호 검증 위치(B), 알람 전체 지우기·재판정 패턴(C): 실제 데이터 연결 범위라 스킬 밖이다.
- 요구서에 없는 단위(mΩ·nA·bar)의 소수 자리(A·D): 기존 규칙대로 사용자에게 묻는다. 시연에서는 질문이 금지라 짐작한 것뿐이다.
- 사이클 타임 목표 30과 측정 30.8의 자릿수 차이(A): 4-1에 적힌 의도대로다.
- 헤더 요약 앞의 "전체 ·"(A·C·D): 기존 4-1 규칙(전체 합계는 "전체 · …")대로다.
- 메인 화면 "상한 65.0"이 레시피 dialog에 없음(A): 프롬프트가 레시피 항목을 지정했다.
