# 3회차 — 문제 → 해결

3회차는 새 Sonnet 에이전트 4개로 진행했다. 프롬프트는 1·2회차와 같다. 4개 모두 빌드 경고 0개, render `점검 0건`이다. 4개 모두 "정한 기준값" 목록을 보고했다(2회차 규칙).

## 2회차 보완이 동작한 것

- C: 2회차에 추가한 "램프 열 제목 중복" 점검이 실제로 걸렸고, C가 그것을 고쳤다.
- D: 2회차에 추가한 `AddContentRow`를 dialog 카드 2×2에 그대로 썼고 `점검 0건`이었다.
- C: `HeightForRows`와 `Columns`로 표를 감싸 쌓는 2회차 규칙대로 배치했다.
- A: 이력 시각 순서를 지켰다(2회차 규칙).
- 경계값이 일관되게 처리됐다. 상한과 같은 값은 4개 시연 모두 알람이 아니었다.

## 문제와 처리

| # | 문제 (출처) | 처리 |
|---|---|---|
| 1 | 경고 구간이 상한을 덮을 때 "상한과 같은 값은 정상(OK)"이라는 문구가 경고 규칙과 충돌해 보인다 (A·C). 두 시연 모두 "경고"로 바르게 해석했다 | 4-1 경계값 문구를 고쳤다: 상한과 같은 값은 알람·NG가 아니다. 경고 구간이 있으면 경고("상한 근접 60.0 (상한 60.0)"), 없으면 OK |
| 2 | 오류 채널의 진행률 카드가 초록 램프로 보인다 (D) | 판정 기준이 없는 값의 규칙을 고쳤다: 갱신 중이면 `Run`, 멈췄으면(오류·대기·정지) `Stop` |
| 3 | 창 제목과 헤더 제목이 다르다 (D) | 4-1 창 제목 항목에 "헤더 제목도 같은 이름"을 추가했다 |
| 4 | 읽기 전용 값을 어떤 컨트롤로 보여 줄지 안내가 없다 (B) | 4c 표에 행 추가: `ApcTextBox { ReadOnly = true }` 또는 `ApcValueCard` |
| 5 | 램프 열 기본 제목 "상태"가 SKILL.md에 없다 (C). render는 잡았다 | 4c 표 행에 적었다: 열 제목 "상태", 글 열은 "판정"·"내용" |
| 6 | 선택 행에서 이탈 값의 글자색이 선택 색에 묻힌다 (C) | **코드**: `ApcGrid`가 셀에 지정한 글자색을 선택 행에서도 유지한다. 4c에 이탈 값 셀 강조 방법(`Style.ForeColor = ApcTheme.Status(kind)` + 굵게)을 추가했고, 점검 2개도 추가했다 |
| 7 | render 생성 실패 메시지에 원인 위치가 없다 (B) | **코드**: 메시지 끝에 "(위치: 클래스.메서드 파일:줄)"을 붙인다(pdb가 있으면 파일과 줄까지). 점검을 추가했다 |
| 8 | 헤더 요약의 항목 순서가 명시돼 있지 않다 (C) | (정상) → 알람 → 경고 → 정지(대기) 순으로 명시했다 |
| 9 | "값 없음이면 이상 사유 문구 없음"이 "정지 · 통신 끊김"과 충돌하는지 애매하다 (A) | 값에서 나온 사유만 쓰지 않는다고 명시했다. 공정 상태 문구("대기"·"통신 끊김")는 쓴다 |

## 규칙으로 남기지 않은 것 (더 안전하다고 판단)

- **MPa 소수 자리 (A):** 사용자가 정한 단위 표다. 없는 단위는 묻는다는 기존 규칙을 유지한다.
- **`Row()`의 Dock Top 여부, dialog 여는 버튼 위치 (A):** 템플릿에서 바로 알 수 있고, 화면마다 판단할 일이다.
- **이력 이벤트 행의 상태색 (A):** 상태색 목록("기록 = Info", "정상 = Run")으로 이미 해결된다.
- **`Row()` 안 Caption과 입력칸의 1px 세로 어긋남 (B):** PNG를 확대해 보니 한글과 라틴 글꼴의 기준선 차이다. 배치 문제가 아니다.
- **수율 카드 Status (B):** 기존 규칙("판정 기준 없는 값 = Run")대로 맞게 처리됐다.
- **Fill 그래프 2개 나란히 배치 (C):** 직접 짠 `TableLayoutPanel`로도 `점검 0건`이었다. 지금은 헬퍼를 만들 근거가 약하다.
- **채널 × 항목 격자 예시, "완료 · 한계 근접" 문구, dialog 카드 Footer (D):** 화면마다 판단할 일이고, 결과도 규칙에 맞았다.
- **관리자 비밀번호 다음 화면, 알람바 갱신 (B·C):** 데이터 연결 범위다.
