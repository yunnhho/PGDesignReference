## 남은 것

**최종 테스트에서 처음 나온 라이브러리 한계 → 수정함 (APC.UI 1.10.0.0)**

1. **`ApcValueCard` Footer 상태 색:** Footer에 값이 2개 이상이면 `FooterStatus` 하나로 전부 칠해져서 정상 값도 빨갛게 나왔다.
   - **수정:** `SetFooterParts(texts, statuses)`를 추가했다. 항목마다 제 판정 색으로 그리고, `Footer`는 " · "로 이은 글이 된다.
   - SKILL.md 4c와 갤러리(BAY-08 카드)에 반영했다.
   - **확인:** C 프로젝트 사본에 적용해 render했다. 습도는 회색, 파티클만 빨강이었고 `점검 0건`이었다.
2. **`ApcGrid` 편집 칸 글자:** 편집 중인 칸만 글자가 작고 위로 떴다.
   - **원인:** 같은 10pt(13.33px)를 셀 글자(TextRenderer)는 14px로, 입력 칸(네이티브 TextBox)은 13px로 그린다.
   - **수정:** 편집 시작 때 편집 전용 스타일 사본에 정수 px로 올린 글꼴을 준다.
   - **확인:** 화면 캡처에서 글자 상자가 25×10으로 셀 글자와 같았다. 세로 위치 차이는 1px 이내였다.
- `build.sh` 결과는 `ALL PASSED (241)`이다.

**규칙으로 남기지 않는 편이 안전한 것 (전 회차 누적)**

- **확정 단위 표에 없는 단위의 소수 자리**(mΩ·nA·MΩ·Pa/s 등): 기존 규칙대로 사용자에게 묻는다. 시연에서는 질문을 금지했기 때문에 생긴 일이다. "정한 기준값" 보고 규칙이 대신 받쳐 준다.
- **데이터 연결 범위**(레시피 값과 판정 기준 연결, 비밀번호 검증, 알람바 지우기): 이 스킬은 화면 껍데기만 만든다.
- **화면마다 판단할 배치**(버튼 위치, 고정 열 폭 값, 그래프 높이·X축 이름표, 카드와 표 중 선택): 모두 render `점검 0건`이었고 PNG에도 문제가 없었다.
